InfoDuoc Sede San Joaquín - Plataforma de Navegación y Directorio
Descripción General
InfoDuoc es una aplicación web (PWA) orientada a pantallas táctiles (modo kiosco) diseñada como proyecto de título para la sede Duoc UC San Joaquín. Su objetivo principal es resolver la necesidad de orientación espacial y acceso a la información institucional de los estudiantes, combinando un mapa arquitectónico interactivo con un directorio digital del personal.

Características Principales
Mapa Isométrico Interactivo (Vista Kiosco): Un sistema de navegación espacial 3D que abarca desde el Piso -1 hasta el Piso 8. Los alumnos pueden tocar los distintos bloques (salas, laboratorios, casinos) para que estos se iluminen y desplieguen una ventana con el nombre exacto del recinto y una fotografía real de su interior.

Directorio Institucional Dinámico: Módulo de contacto estructurado mediante tarjetas limpias y expandibles. Se divide en dos áreas visuales:

Escuelas: Listado interactivo de las áreas académicas (Informática y Telecomunicaciones, Ingeniería y Recursos Naturales, Salud y Bienestar) que despliega banners fotográficos y los perfiles de los Directores de Carrera y Orientadores.

Equipo de Sede: Tarjetas de contacto directo para la Dirección, Punto Estudiantil, Financiamiento y Pastoral, con fotografía, cargo y correo.

Panel de Administración Integral (CRUD): Un sistema de gestión protegido tras un "acceso oculto" en el logotipo principal del sistema. Permite a los administradores de la sede actualizar la plataforma visualmente: modificar nombres de recintos, subir nuevas fotografías de las salas y actualizar toda la información del directorio sin necesidad de conocimientos de programación.

Stack Tecnológico
Frontend: React (Arquitectura basada en componentes).

Enrutamiento: TanStack Router para una navegación fluida y sin recargas de página.

Estilos y UI: Tailwind CSS para el diseño de la interfaz institucional, las animaciones suaves y la simulación del entorno 3D isométrico.

Gestión de Entorno: Node.js, NPM y Git para control de versiones en GitHub.
